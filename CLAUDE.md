# anthropic-laravel

## Project

`mozex/anthropic-laravel` — A Laravel integration package wrapping `mozex/anthropic-php` (framework-agnostic Anthropic API client). Exposes the client via a service provider, facade, connection manager, the `anthropic:install` and `anthropic:doctor` commands and an `about` section. Namespace: `Anthropic\Laravel\`. Requires PHP 8.2+, Laravel 12 or 13.

## Commands

```bash
composer lint             # Fix code style with Pint
composer test             # Run ALL checks: lint, types, type coverage, unit tests
composer test:lint        # Check code style without fixing
composer test:types       # Run PHPStan (level max)
composer test:type-coverage  # Verify 100% type coverage
composer test:unit        # Run Pest unit tests
```

Run a single test file:
```bash
./vendor/bin/pest tests/Facades/AnthropicTest.php
```

Run tests by name:
```bash
./vendor/bin/pest --filter="test name substring"
```

## Architecture

Small package with 19 source files in `src/`:

- **`ServiceProvider.php`** — `DeferrableProvider` that registers `ClientContract` as a lazy singleton (built by `ClientBuilder` from the top-level config, through `ClientBuilder::withLaravelAi()`), aliased to `'anthropic'` and `Client::class`, and `AnthropicManager` as a singleton. Auto-discovered via `extra.laravel.providers` in `composer.json`. Publishes `config/anthropic.php` under the provider and the `anthropic-config` tag.
- **`Facades/Anthropic.php`** — Facade resolving `AnthropicManager`. Has `fake(array $responses)` for testing: it loads the deferred provider first (in a container that still defers it, `loadDeferredProviders()`, which every `artisan()` call runs, would otherwise bind the real client over the fake), binds the `AnthropicFake` as `ClientContract`, then hands it to the manager (`useFake()`), or swaps the root in a container without the manager. Code that type-hints `Anthropic\Client` can't take the fake; the docs say to type-hint `ClientContract`.
- **`Testing/AnthropicFake.php`** — Thin subclass of `Anthropic\Testing\ClientFake` whose protected `$connection` is `default`, so calls through the fake itself (an injected `ClientContract`) count as the default connection's. Provides `assertSent()`, `assertNotSent()`, `assertNothingSent()`, `assertSentOn()`, `assertNotSentOn()`.
- **`Exceptions/ApiKeyIsMissing.php`** — `create()` when the default connection has no `api_key` string, no `auth_token` and no laravel/ai key; `forConnection()` for a named connection without either; `forKey()` for a missing `admin_key`, `enterprise_key` or `compliance_key`.
- **`Commands/InstallCommand.php`** — `php artisan anthropic:install`. Copies config, appends env vars to `.env`/`.env.example`, then asks for a GitHub star (default yes). Uses Termwind for console output via `Support/View.php`. A run nobody can answer (`--no-interaction`, or no terminal on stdin, as with CI and AI agents) skips the question, takes the default, and prints a note explaining the browser tab. `isInteractive()` treats unit tests as interactive, like Laravel's own prompt rule, so the tests are deterministic. The question uses `$this->confirm()`, not Laravel Prompts: the earlier `callSilent('vendor:publish')` reconfigures Prompts' global output to a `NullOutput`, which would make a Prompts question invisible. The browser opens through the `Process` facade (backgrounded on Linux, where `xdg-open` without a detected desktop runs the browser in the foreground), and any failure prints the URL instead.
- **`Support/View.php`** — Termwind console view renderer using PHP templates from `resources/views/components/`.
- **`Commands/DoctorCommand.php`** — `php artisan anthropic:doctor [--connection=] [--offline]`: the credential (`ClientBuilder::hasCredential()`, so an empty key line fails; offline it only warns, so a keyless pipeline still checks the queues), one `models()->list(['limit' => 1])` (no tokens; any exception fails it), `queue.default`'s (and its failover members') and Horizon's queues' `retry_after` (a redis or database one without it is Laravel's 60; others only warn; a used SQS connection warns about its visibility timeout) and, as a warning since a job's `$timeout` wins, each supervisor `timeout` Horizon runs here (picked as Horizon does: `horizon.env` or the app's, the first `Str::is()` match in config order, none without one, no zero-process supervisors) against `request_timeout × (max_retries + 1) × (1 + fallback models)` plus the client's backoff (`ClientBuilder::requestTimeout()` and `fallbackModels()`, which the builder uses too; 0 fails), the fallback models only after the API check passed, the `fallback_models` lifecycle through the client's `isRetired()` (a failure), `isRetirementOverdue()` and `isRetiring()` (warnings), and a warning for Livewire with Octane. A failure exits non-zero; a warning doesn't. It reads the connection's settings through the manager's public `getInstanceConfig()`.
- **`Support/About.php`** — the Anthropic section of `php artisan about`, which the eager provider registers with `AboutCommand::add()` (resolved only when `about` runs): versions, the credential's kind (never its value), the request timeout, the connections, and `Client::settings()` of the default client. It lives outside the provider because Pest's arch rules can't allow `Composer\InstalledVersions`.
- **`resources/boost/guidelines/core.blade.php`** — the always-loaded Boost guideline: the skill's five traps and the `retry_after` rule in six lines. Keep it that short; the detail belongs in the skill.
- **`AnthropicManager.php`** — the facade's root, on Laravel's `MultipleInstanceManager` (`Macroable`, `@mixin ClientContract`): the default connection is `$app->make(ClientContract::class)` (so an app's `extend(ClientContract::class)` reaches `Anthropic::`), named ones under `anthropic.connections` are `array_replace()` (shallow) over the top-level keys, minus both credentials when the connection sets either, and cached; a named one without a credential throws `ApiKeyIsMissing::forConnection()` and never takes laravel/ai's key. `withApiKey()` builds a fresh client each call, without the default's `workspace_id` (it belongs to the app's key; another organization's key sent with it gets a 404); `organization()`/`enterprise()`/`compliance()` use `admin_key`/`enterprise_key`/`compliance_key` (Bearer), without the default's `workspace_id`, cached in their own `$keyed` array, and their names are reserved (`connection('organization')` throws, faked or not). Both start from the default settings through `ClientBuilder::withLaravelAi()`, so they follow laravel/ai's URL as the default does. It holds the fake from `Anthropic::fake()` in its own property (never `$instances`), and every path, the inherited `instance()` included, returns `$fake->onConnection($name)`. `forgetConnection()` with no name forgets every named connection and keyed client, never the default, which is the container's `ClientContract` (forgetting it would drop an app's `instance()` binding or a late `extend()`); the eager provider calls it on `Looping` and Octane's `OperationTerminated` (by name) only when the manager was resolved.
- **`ClientBuilder.php`** — builds one connection's client through the client's `Factory::withConfig()`, which validates the keys it takes (credentials, workspace, version, base URL, betas, `max_retries`, `middleware`, `headers`: a wrong type throws, naming the key; `beta` drops its non-string entries first, as 1.9.0 did), while the builder reads its own (`fallback_models`, `request_timeout`, `connect_timeout`, `http`) leniently as before; `hasCredential()` (a non-blank key or token, so an empty `ANTHROPIC_API_KEY=` line counts as none) decides the fallback and a named connection's `ApiKeyIsMissing`; `withLaravelAi()` (`ai.providers.anthropic.key` and `url` as a pair, as `base_uri`, only without a key or token of this package; the default settings only), the Guzzle client and its `http` stack, then the client middleware: the fallback, `DispatchesEvents` (with the connection's name), `AddsToContext` (with `context`), `RecordsInTelescope` (with `http.telescope`), then the connection's `middleware`. Every method that holds a connection's config array or a key while something below it can throw marks it `#[SensitiveParameter]` (Flare turns `zend.exception_ignore_args` off and collects a trace's arguments), and so do the facade's own `__callStatic()` (Laravel's body copied, since calling `parent::__callStatic()` would add a frame holding the arguments unmarked) and the manager's `__call()`; `ManagerTest`'s "a config error keeps the keys out of the trace" checks each but the doctor's, which `DoctorTest` checks by reflection, and a new one gets a row in one of them. Nightwatch's Guzzle middleware goes first on the Guzzle stack, resolved per attempt (Guzzle caches a resolved stack, and Nightwatch reads `Nightwatch::ignore()` there), and only while `nightwatch.enabled` isn't false.
- **`AnthropicServiceProvider.php`** — the eager provider (auto-discovered beside the deferred one): only what runs before the client is resolved: the listeners that forget the manager's connections, and in the console the `about` section (`Support/About`).
- **`Events/`** — `RequestSending`, `ResponseReceived`, `RequestFailed`, `RateLimited`: plain classes of scalars and arrays (the arch suite lets them use nothing), so queued listeners can take them.
- **`Middleware/DispatchesEvents.php`** — the client middleware that dispatches them per attempt.
- **`Middleware/AddsToContext.php`** — with `anthropic.context`, keeps each answer's request ID in Context's `anthropic_request_ids` (the last 20: every log line and dispatched job carries them) and increments `anthropic_input_tokens`/`anthropic_output_tokens` from a non-streamed Messages answer's `usage` (a path ending in `/messages`); the Context repository is resolved per attempt (it's scoped to a request or job, and the client outlives them).
- **`Middleware/RecordsInTelescope.php`** — with `http.telescope` and Telescope installed, records each attempt through `Telescope::recordClientRequest()` with tags `anthropic`, `model:`, `req:`, applying Telescope's hidden headers and parameters and its watcher's 64 KB purge.
- **`Middleware/Concerns/ReadsMessages.php`** — what every recorder shares: credential headers (`/(key|token|secret|auth|cookie|password)/i`) and the URL's user info and query removed, and any body field named `authorization_token` (an MCP server's, a batch's included) masked as `********`, so no event, Telescope entry or Laravel event carries a credential. A new recorder uses it.

**Config** (`config/anthropic.php`): `anthropic.api_key` (env `ANTHROPIC_API_KEY`), `anthropic.request_timeout` (env `ANTHROPIC_REQUEST_TIMEOUT`, default `30`), `anthropic.beta` (env `ANTHROPIC_BETA`, a comma-separated list the provider joins into a global `anthropic-beta` header), `anthropic.api_version` (env `ANTHROPIC_API_VERSION`) and `anthropic.base_url` (env `ANTHROPIC_BASE_URL`), plus `anthropic.auth_token` (`ANTHROPIC_AUTH_TOKEN`, sent as Bearer through `withAuthToken()` only when no key is set: one credential, as in the official SDKs; `ApiKeyIsMissing` only when neither is set), `anthropic.workspace_id` (`ANTHROPIC_WORKSPACE_ID`), `anthropic.connect_timeout` (`ANTHROPIC_CONNECT_TIMEOUT`, Guzzle's `connect_timeout` when a positive number), `anthropic.max_retries` (`ANTHROPIC_MAX_RETRIES`, a whole number of 0 or more; anything else throws), `anthropic.fallback_models` (`ANTHROPIC_FALLBACK_MODELS`, comma-separated; a non-empty list adds the client's `RefusalFallbackMiddleware` without a shared `FallbackState`, so a long-lived worker's singleton never pins every user to a fallback), `anthropic.http.laravel_client` (`ANTHROPIC_HTTP_LARAVEL_CLIENT`; the innermost Guzzle middleware builds Laravel's global middleware, recorder and stub handlers from the HTTP factory on each attempt, so an `Http::fake()` or `Http::preventStrayRequests()` set after the client was built applies and the app's `http.middleware` runs before the fake; Laravel's before-sending handler is left out, so its `RequestSending` never fires unpaired), `anthropic.http.laravel_events` (`ANTHROPIC_HTTP_LARAVEL_EVENTS`; `Middleware\DispatchesEvents` also dispatches Laravel's `RequestSending` and then `ResponseReceived` or `ConnectionFailed`, as a pair, streams included, from the request with its credential headers removed). `Middleware\DispatchesEvents` (added after the fallback, when a dispatcher is bound; the dispatcher is resolved per attempt, so a later `Event::fake()` applies, and a fake counts as listening) dispatches `Events\RequestSending`, `ResponseReceived`, `RequestFailed` and `RateLimited` per attempt, with scalars and arrays only, no header whose name holds `key`, `token`, `secret`, `auth`, `cookie` or `password`, only JSON bodies decoded (never an upload), an error answer buffered before it's read, and no event built that nobody listens to. `anthropic.middleware` (client middleware class names the container resolves, or callables, run around every attempt after `DispatchesEvents`; a connection can carry its own), `anthropic.connections` (named connections, above), `anthropic.http.telescope` (`ANTHROPIC_HTTP_TELESCOPE`, off), `anthropic.http.nightwatch` (`ANTHROPIC_HTTP_NIGHTWATCH`, on: `ClientBuilder` attaches `$app->make(Laravel\Nightwatch\Core::class)->guzzleMiddleware()` only when the class exists, its `Core` is bound, `nightwatch.enabled` isn't false and `laravel_client` is off, since Nightwatch's own global HTTP client middleware already records that path), `anthropic.context` (`ANTHROPIC_CONTEXT`, off). Telescope and Nightwatch are `suggest` entries and dev dependencies (every reference sits behind a `class_exists()` check), so PHPStan and the tests use the real classes. `anthropic.http.middleware` (Guzzle middleware class names the container resolves, or callables, pushed onto a `HandlerStack` `ClientBuilder` builds; one class name alone counts as a list, and an entry that isn't a middleware throws `InvalidArgumentException`) and `anthropic.headers` (an array of string, int or float values, null and blank ones skipped and anything else throwing, no env variable, applied last). `auth_token`, `workspace_id`, `api_version` and `base_url` default to null and apply only as non-blank strings, so a config published before they existed (the provider merges no defaults) keeps the client's own defaults. `base_url` has the official SDKs' meaning, the URL without the API's `/v1`: `ClientBuilder` passes it as `withConfig()`'s `base_url`, which goes to the client's `withBaseUrl()`, which trims it and adds `/v1` unless it already ends in `/v1` (one rule for both packages).

The install command adds each `.env` key a file lacks (an anchored match, commented lines count), so a re-run brings an older `.env` up to date. The optional keys go in commented out: other packages read the same names (Prism reads `ANTHROPIC_API_VERSION`), and Laravel's `env()` returns `''` for an empty line, which drops their default. When `config/anthropic.php` already exists, it names the keys the package's config has that the published copy lacks, since their `.env` variables do nothing until they're added.

**Underlying client** (`mozex/anthropic-php`) exposes `->messages()`, `->completions()`, `->models()`, `->batches()`, `->files()`, `->withOptions()` and `->request()` (raw requests to any path; the fake records them under `Anthropic\Resources\Raw::class`); the list resources have `iterate()`.

## Code Conventions

- All files use `declare(strict_types=1)`
- No class is `final`: users extend package classes
- Non-public-API classes use `@internal` docblock
- No debugging statements: `dd`, `ddd`, `dump`, `ray`, `die`, `var_dump`, `print_r`
- PHPStan at level `max` on `src/` and `config/`, with Larastan — no baseline. The one ignore is Larastan's `noEnvCallsOutsideOfConfig` for `config/anthropic.php`, where `env()` belongs
- Pint with default Laravel ruleset (no `pint.json`)

## Testing

Tests use **Pest** syntax with `expect()` assertions. Every test file ends in `Test.php`: `phpunit.xml.dist` lists `tests` without a suffix, so PHPUnit's default `Test.php` applies and any other file there is silently skipped (a test in `tests/ArchTest.php` fails on one). `tests/Pest.php` binds nothing: the facade and provider tests build their own container. Testbench, like an app's own test case, bootstraps the console kernel, which loads every deferred provider before a test runs, so a test about deferred loading (the fake test after `loadDeferredProviders()`) builds a fresh `Illuminate\Foundation\Application` with `addDeferredServices()` and restores the global container and the facade application afterwards.

Architecture tests in `tests/ArchTest.php` enforce namespace dependency boundaries — each namespace declares which imports are allowed.

`tests/InstallCommandTest.php` runs the install command, and `vendor:publish` by tag and by provider, through Orchestra Testbench (`tests/TestCase.php` registers both providers); `tests/EventsTest.php` is bound to it too. It fakes `Process`, so no test opens a real browser, and restores the testbench skeleton's `.env.example` afterwards.

Facade fake pattern:
```php
Anthropic::fake([CreateResponse::fake(['id' => 'msg_test'])]);
$result = Anthropic::messages()->create([...]);
Anthropic::assertSent(Messages::class, fn (string $method, array $parameters) => $method === 'create');
```

## CI

Tests run across: PHP 8.2-8.5, Laravel 12/13 (with their testbench and carbon versions; Laravel 13 skips PHP 8.2), prefer-lowest/prefer-stable. There's no Pest dimension: prefer-stable cells get the newest Pest major each PHP version allows, prefer-lowest cells the oldest one that resolves (Pest 3 with Laravel 12).
